## 命名规范

本项目所有数据库表统一遵循以下规则：

- 主键固定命名为 `id`
- 外键（引用其他表的id）命名为 `表名单数_id`，例如 `user_id`、`post_id`
- 创建时间字段固定命名为 `created_at`
- 更新时间字段固定命名为 `updated_at`
- 布尔值（是否类）字段以 `is_` 开头，例如 `is_deleted`
- 所有字段名统一使用小写字母 + 下划线（snake_case），不使用驼峰命名或大写字母

## users 表（用户表）

存放用户注册信息。

| 字段名 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| id | INT，自增，主键 | 是 | 用户唯一编号 |
| username | VARCHAR(50) | 是，唯一 | 用户名，登录凭证 |
| password_hash | VARCHAR(255) | 是 | 加密后的密码，用bcrypt加密，绝不存明文 |
| avatar | VARCHAR(255) | 否 | 头像图片链接，可为空 |
| created_at | DATETIME | 自动填 | 注册时间，默认当前时间 |

**建表语句：**
```sql
CREATE TABLE users (
  id INT AUTO_INCREMENT PRIMARY KEY,
  username VARCHAR(50) NOT NULL UNIQUE,
  password_hash VARCHAR(255) NOT NULL,
  avatar VARCHAR(255),
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

**关联接口：**
- POST /api/auth/register（用户注册）
